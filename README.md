# 阅卷助手网页版

给多位助教使用的统一批改工作台。首页只有试题、参考答案、评分细则、本地答题卡文件夹和 OpenAI API key 五项主要输入；高级参数折叠。自动输出 AI 建议成绩，人工复核可选，按学号查看和改分，改判理由允许留空。

访问方式：拿到网址即可打开，无需安装、登录或下载程序。[打开在线网站](https://probability-grading-assistant.zestyhinny18.chatgpt.site)。每位助教使用自己的 API key，自己的批次进度保存在自己的浏览器中。网站未内置付费密钥或学生材料。

## 助教操作

1. 先用右上角“先体验演示”熟悉流程。演示材料与分数均为合成，不调用 API。
2. 上传教师提供的试题、参考答案和评分细则，支持 PDF、DOCX、PNG/JPEG/WebP、UTF-8 文本。每个文件最大 3 MiB，三份材料合计最大 6 MiB。
3. 选择整理好的本地答题卡文件夹，填写自己的 OpenAI API key，确认材料处理后点“整理评分规则”。这一步会产生 API 费用。核对生成的题号、满分和评分点，再开始批改。材料缺失或冲突会提示补充，不能静默猜分。
4. 六位助教应使用同一份经负责人核对的规则：第一人下载“统一评分规则”，其余助教直接导入，避免反复整理或细则漂移。
5. 等待结果，保持网页打开。可暂停、下载进度备份和导出建议成绩 CSV。建议成绩不要求逐题人工复核。
6. 需要时输入学号，点“查看 / 改分”。选择逐点评分、填写复核人即可保存，理由选填。重新打开页面后，重新选择原文件夹即可查看原图及改分，无需 API key；只有继续调用 API 才需要密钥。

## 文件夹要求

```text
本批答卷/
  2026001/
    Q1/01.jpg
    Q1/02.jpg
    Q2/01.pdf
  2026002/
    Q1/01.jpg
    Q2/01.jpg
```

也支持 `2026001_Q1_01.jpg`。保留同题续页，用 01、02 等编号顺序。每个作答文件最大 3 MiB，每题合计最大 6 MiB、最多 30 个文件。整份学生试卷 PDF 须先按题拆分；软件不会自动识别学号、分卷或裁切试卷。不要把身份首页放入处理文件夹；作答图像本身也应去除身份信息。程序不会自动遮盖图片中的姓名、学号。

缺题、未知、读不清和调用失败不作零分；未完成题目使建议总分留空。文件夹完全未包含某位同学时无法自行推断，可在“更多设置”填应收学号名单。路径或内容与原记录不一致时停止绑定，避免把新图关联到旧分数。

## 保存、费用与恢复

- 原图只由浏览器读取，按当前题目发送给本站处理接口，再转发到 OpenAI。本站没有答卷数据库、文件存储或共享批次列表；学号映射留在浏览器，模型收到的是本题规则及匿名证据编号。OpenAI 的数据处理按其服务政策执行。
- 密钥只保留在当前页面内存和本次 HTTPS 请求中；应用不会将其写入浏览器持久存储、日志、导出或源码。刷新后重新填写，不要把密钥发到聊天或成绩文件。
- 本地进度记录规则、文件哈希、请求编号、API 原始结果和用量、人工修改历史。进度备份和 CSV 可能含学号、作答描述，应保存在助教自己的受控位置。
- 关闭网页会停止后续请求。已发出的请求可能已经计费；刷新后不自动重试该请求。已保存成绩和人工改分会保留；网络请求中断或服务器异常时暂停整批。文件需重新选择，按路径和 SHA-256 核对后续跑。整理好的规则草案在尚未开始批改时也能恢复，但需要重新核对确认。浏览器清理数据会丢失本机进度，请定期下载备份。换电脑需导入备份并携带原答卷；已收费但响应丢失的调用不能保证找回。
- 默认每分钟 1 次请求，本批预算 100 元、每次预留 5 元，可在开始前展开“更多设置”调整。A 路主评、B 路独立质检，不平均，人工改分优先。使用模型 `gpt-6.1-terra`，medium，最多 8000 输出 token。
- 费用是按用量和程序费率估算，人民币系数 7.5 仅作预算，实际以 API 账单为准。预算预留不能保证最终账单绝不超额；当前请求费用可能超过预留。无法确认费用时保留预留并提示核查。无自动重试、无后台执行。
- 每个服务实例限制同时处理的请求，繁忙时明确返回“未发出 API”，助教稍后手动重试。此限制不代表已通过六人并发压力验收，也不是 OpenAI 账号速率限制。
- 同一浏览器的同批次通过 Web Locks 防止多标签重复处理。建议最新版 Chrome 或 Edge；不支持共享编辑同一批次。

## 当前验证范围

已实现离线演示、严格分值与证据校验、断点恢复、费用账本、可选复核、CSV 与进度备份。81项离线测试通过，包含网络错误、服务器异常、保存失败和草案恢复。测试使用模拟接口，不调用真实 API。没有真实手写卷的准确率、真实费用、六人并发或大规模性能实测；先做教师评分对照的小样，再决定正式批次。程序导出的是建议成绩，正式考试成绩由教师或授权助教实质审阅确认。

## 源码与重现

- `app/page.tsx`、`app/globals.css`：简化操作页和样式。
- `lib/grading/validation.mjs`：评分规则、分值、证据和建议分逻辑。
- `lib/grading/browser-workflow.mjs`：文件核对、浏览器账本、任务队列、导出和演示。
- `lib/grading/api-service.mjs`、`app/api/`：无状态 OpenAI Responses 接口。固定官方地址、禁止重定向、不接收自定义服务商地址；不记录请求内容。
- `tests/`：离线验证。运行 `node --test tests/*.test.mjs`；类型检查 `node node_modules/typescript/bin/tsc --noEmit`。
- 网站使用 Sites Vinext 模板。需 Node 22.13+，先运行 `npm run install:ci`，开发 `npm run dev`。通过已安装 Sites 插件的 `build-site.mjs` 与 `site-workflow.mjs` 构建、同步并发布；自建部署应在自己的账户注册站点，再配置 `.openai/hosting.json`。这是带服务端接口的网站，不能仅上传到静态 GitHub Pages 就完成 API 处理。
- 本仓库仅包含网页程序、构建依赖声明、说明及合成测试。公开源码不含现有网站的部署编号；不要加入学生文件、导出、密钥或本机运行状态。`.sites-runtime/`、`dist/`、`node_modules/` 是可重建且已忽略的本地依赖与构建目录。

官方接口依据：[模型说明](https://developers.openai.com/api/docs/models/gpt-6.1-terra)、[文件输入](https://developers.openai.com/api/docs/guides/file-inputs)。费率为 2026-10-29 核对的快照，不保证以后不变。
